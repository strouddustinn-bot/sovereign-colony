## Required metadata

- Stable artifact ID
- Colony and run identifier
- Colony day and event sequence
- Author citizen IDs and genome IDs
- Artifact type and content digest
- Source event IDs
- Resource cost
- Validation method and result
- Governance disposition
- Current status
- Related Git commit, test report, or state digest

Artifacts lacking provenance are quarantined rather than silently discarded.
