# Roadmap

## Phase 0 — Constitutional specification

- [x] Project thesis and boundaries
- [x] Initial constitution
- [x] Kernel/world architecture
- [x] Citizen contract
- [x] Event vocabulary
- [x] 100-day experiment protocol
- [ ] Threat model
- [ ] JSON Schemas for all contracts
- [ ] Architecture decision records

## Phase 1 — Deterministic world kernel

- [ ] Hash-chained SQLite event ledger
- [ ] Pure state reducer and digest
- [ ] Resource accounting
- [ ] Capability and policy evaluator
- [ ] Replay, fork, pause, reset, and rollback
- [ ] RED/GREEN acceptance tests for each invariant

## Phase 2 — Scripted civilization

- [ ] Five deterministic founding citizens
- [ ] Proposals, votes, quorum, appeals, and law activation
- [ ] Pheromone decay and cultural compression
- [ ] Genome lineage and bounded mutation
- [ ] Complete 100 deterministic days

## Phase 3 — Sandboxed execution

- [ ] Rootless isolated world runner
- [ ] No-network default and fixed dependency mirror
- [ ] Resource ceilings and teardown verification
- [ ] Adversarial escape and supply-chain tests

## Phase 4 — LLM citizens

- [ ] Model adapter behind typed citizen contract
- [ ] Output parsing and fail-closed validation
- [ ] Persist every model output as evidence
- [ ] Compare scripted and LLM societies under identical seeds

## Phase 5 — Observation

- [ ] Replay UI
- [ ] Lineage and institution graph
- [ ] Resource and fitness dashboard
- [ ] Experiment comparison and reproducibility bundle

## Explicitly deferred

- Host tool access
- Open internet
- Autonomous external deployment
- Cryptocurrency or real-money economy
- Human impersonation
- Self-expanding compute
- Kernel self-modification
